### Shared-memory primitives (external-process LCD bridge)
- `InitMemorySize` (Form1.cs:132) — creates-or-opens the named memory-mapped file `shareMemory_Image` with capacity 38,400,000 bytes into field `shareMemory`. That is exactly 250 slots of the 153600-byte frame stride used by `ReadShareMemory`/`WriteShareMemory`. No branches.
- `ReadShareMemory` (FormLCD.cs:330) — reads `count` bytes (default 1048576 = 1 MiB) out of the memory-mapped file `shareMemory` starting at block offset `n * 1048576` into the caller's buffer, then closes and disposes the view stream. Block index `n` selects the slot: 0 = theme/display config, 1 = system-info overlay config, 2 = pointer feedback from the helper app. No branches.
- `WriteShareMemory` (FormLCD.cs:338) — writes `count` bytes (default 1048576 = 1 MiB) from the caller's buffer into the memory-mapped file at block offset `n * 1048576`, then closes and disposes the view stream. Used both for full-block publishes and for the 1-byte ready-flag commit at byte 0 of a block. No branches.
- `CloseShareMemory` (Form1.cs:153) — disposes the `shareMemory` mapped file handle (`shareMemory_Image`). No branches.
- `InitMemorySizeRGB` (Form1.cs:158) — creates-or-opens the named memory-mapped file `shareMemory_ImageRGB` with capacity 34,560,000 bytes into field `shareMemoryRGB`. That is exactly 50 slots of the 691200-byte stride used by the RGB accessors (691200 = 480x480 at 3 bytes per pixel). No branches.
- `ReadShareMemoryRGB` (Form1.cs:163) — opens a view stream on `shareMemoryRGB` at byte offset `n * 691200` with length `count` (defaults `n` = 0, `count` = 691200), reads `count` bytes into `shareMemoryValRGB` at offset 0, then closes and disposes. Discovery polling calls it with `count` = 100 to read only the descriptor header of a slot. No branches.
- `WriteShareMemoryRGB` (Form1.cs:171) — opens a view stream on `shareMemoryRGB` at byte offset `n * 691200` with length `count` (default 691200), writes `count` bytes from the supplied array starting at offset 0, then closes and disposes. Used both for full RGB frames and for short control headers (4-byte shutdown sentinel, 8-byte slot clear). No branches.
- `CloseShareMemoryRGB` (Form1.cs:179) — `shareMemoryRGB.Dispose()`. No branches.
