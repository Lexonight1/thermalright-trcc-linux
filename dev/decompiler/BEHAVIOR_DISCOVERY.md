- `InitMemorySize` (Form1.cs:132) — creates-or-opens the named memory-mapped file `shareMemory_Image` with capacity 38,400,000 bytes into field `shareMemory`. That is exactly 250 slots of the 153600-byte frame stride used by `ReadShareMemory`/`WriteShareMemory`. No branches.
- `ReadShareMemory` (Form1.cs:137) — opens a view stream on `shareMemory` at byte offset `n * 153600` with length 153600 (default `n` = 0), reads all 153600 bytes into the `shareMemoryVal` buffer at offset 0, then closes and disposes the stream. 153600 = 320x240 at 2 bytes per pixel (RGB565). No branches.
- `WriteShareMemory` (Form1.cs:145) — opens a view stream on `shareMemory` at byte offset `n * 153600` with length `count` (default 153600), writes `count` bytes from the supplied array starting at offset 0, then closes and disposes. - `CloseShareMemory` (Form1.cs:153) — disposes the `shareMemory` mapped file handle (`shareMemory_Image`). No branches.
- `InitMemorySizeRGB` (Form1.cs:158) — creates-or-opens the named memory-mapped file `shareMemory_ImageRGB` with capacity 34,560,000 bytes into field `shareMemoryRGB`. That is exactly 50 slots of the 691200-byte stride used by the RGB accessors (691200 = 480x480 at 3 bytes per pixel). No branches.
- `ReadShareMemoryRGB` (Form1.cs:163) — opens a view stream on `shareMemoryRGB` at byte offset `n * 691200` with length `count` (defaults `n` = 0, `count` = 691200), reads `count` bytes into `shareMemoryValRGB` at offset 0, then closes and disposes. - `WriteShareMemoryRGB` (Form1.cs:171) — opens a view stream on `shareMemoryRGB` at byte offset `n * 691200` with length `count` (default 691200), writes `count` bytes from the supplied array starting at offset 0, then closes and disposes. - `CloseShareMemoryRGB` (Form1.cs:179) — `shareMemoryRGB.Dispose()`. No branches.

On a text hit it sets BOTH `isMouseDown` (the transient drag handle, cleared on mouse-up) and `isDMouseDown` (the sticky selection used by the keyboard nudger, NOT cleared on mouse-up) and fires the delegate with mode 1 and the element index (2042).
